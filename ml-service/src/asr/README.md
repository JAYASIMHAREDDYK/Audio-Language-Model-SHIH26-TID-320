## 🏗️ Deep Conformer Architecture Specifications

- **Input Representation:** 80-bin Log-Mel Spectrogram (16 kHz sampling rate, 25ms window, 10ms hop).
- **Subsampling Frontend:** 2× 2D Depthwise-Separable Convolutional Subsampling with stride 2 ($4\times$ temporal reduction: $T_{enc} = T_{mel} // 4$).
- **Conformer Blocks:** 12 stacked Conformer blocks.
  - Multi-Head Self-Attention: 8 attention heads, $d_{model} = 512$.
  - Feed-Forward Networks: Macaron-style half-step FFNs with $d_{ff} = 2048$.
  - Convolution Module: Depthwise 1D convolution with kernel size 31, Swish / SiLU activation, BatchNorm.
  - Regularization: SpecAugment (Frequency masking $F=27$, Time masking $T=40$), Dropout = 0.1.
- **CTC Decoder Head:** Linear projection $512 \to 2122$ covering full 7-language unified vocabulary (Devanagari, Telugu, Tamil, Bengali, Kannada, Mandarin Hanzi, Latin) and language conditioning tokens.

## 📦 How Jay Imports & Uses `ASRModel`

Jay's temporal fusion module can import and call `ASRModel.encode()` without knowing anything about internal ASR mechanics:

```python
import torch
from src.asr import ASRModel

# 1. Initialize ASR Model (CUDA or CPU)
asr = ASRModel(device="cuda" if torch.cuda.is_available() else "cpu")

# 2. Extract Speech Embeddings for Temporal Fusion
# audio can be a file path, raw bytes, numpy array, or torch tensor
audio_path = "path/to/threat_audio.wav"

# Frame-level embeddings: (Batch, Time_Frames, Embedding_Dim) -> (1, T, 512)
frame_embeddings = asr.encode(audio_path)

# Pooled acoustic vector: (Batch, Embedding_Dim) -> (1, 512)
pooled_embedding = asr.encode(audio_path, pool=True)

# Full representation dictionary
features = asr.get_speech_embeddings(audio_path)
print("Frame Shape:", features["frame_embeddings"].shape)  # (1, T, 512)
print("Embedding Dim:", features["embedding_dim"].item())   # 512

# 3. Auxiliary Multilingual Transcription
transcript_result = asr.transcribe(audio_path, language="hi")
print("Transcribed Text:", transcript_result["text"])
print("Confidence:", transcript_result["confidence"])
print("Detected Language:", transcript_result["language"])
```
